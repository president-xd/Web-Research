# Web-Security Papers 2025-2026

**73 papers** (60 web-core, 13 web-adjacent), 175.0 MB, in `papers/`.

Every paper was validated against its **extracted abstract**, not just its title. See `validation.csv`
for the per-paper evidence (matched web terms + abstract text).

- **WEB-CORE** - a direct web attack surface, web protocol/browser issue, or web privacy measurement.
- **WEB-ADJACENT** - web-enabling infrastructure (DNS, web PKI, TLS) or a web-language runtime,
  where the paper's core contribution is not itself a web attack surface.
