# Offensive-Papers (70 papers)

Attacks, exploitation, vulnerability discovery, and offensive measurement of the web.

Part of the [Web-Security Papers collection](../../README.md). Companion set: [Defensive-Papers](../Defensive-Papers/README.md).

## Topics

- **[Tracking and Fingerprinting](Tracking-and-Fingerprinting/)** (14) — Browser/mobile fingerprinting and tracking techniques and measurements that expose user surveillance.
- **[HTTP Protocol and Transport Attacks](HTTP-Protocol-and-Transport-Attacks/)** (9) — HTTP/2-3 issues, request smuggling/desync, CDN translation anomalies, WebRTC, and TLS-layer attacks on web servers.
- **[Web App Vulnerability Discovery and Scanning](Web-App-Vulnerability-Discovery-and-Scanning/)** (9) — Black/grey-box scanners, crawlers, and fuzzers that find server-side and web-application vulnerabilities.
- **[Authentication Identity and Access Attacks](Authentication-Identity-and-Access-Attacks/)** (8) — Attacks on logins, OAuth, credentials, password managers, autofill, FIDO2, QR-login, and identity/age verification.
- **[Injection Taint and Deserialization](Injection-Taint-and-Deserialization/)** (8) — SQL/command/code injection, taint-style bugs, prototype pollution, and (de)serialization gadget chains.
- **[Phishing Scams and Web Abuse](Phishing-Scams-and-Web-Abuse/)** (5) — Phishing, scam campaigns, URL-shortener/e-commerce abuse, and evasion of phishing detectors.
- **[Runtime Engine and Browser Internals](Runtime-Engine-and-Browser-Internals/)** (5) — Bugs and exploitation in JS engines, the PHP interpreter, and browser policy-enforcement internals.
- **[XSS and DOM](XSS-and-DOM/)** (4) — Cross-site scripting, DOM-based XSS, and DOM clobbering.
- **[DoS and Availability](DoS-and-Availability/)** (2) — Denial-of-service and amplification against web containers and CDNs.
- **[Domain and DNS Takeover](Domain-and-DNS-Takeover/)** (2) — Domain/subdomain and DNS-based hijacking that enables web takeover.
- **[Payment and Authorization Attacks](Payment-and-Authorization-Attacks/)** (2) — Breaking third-party online payments and emerging web-payment protocols.
- **[Web Agent and LLM Attacks](Web-Agent-and-LLM-Attacks/)** (2) — Red-teaming and threat analysis of LLM-driven web agents and web-enabled LLMs.
